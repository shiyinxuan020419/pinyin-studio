# 小象语文 · 课文排版工作台

在左侧编辑文字、拼音与换行，右侧实时查看课节目录的排版效果。

- 原稿、16:9、21:9、4:3 预览。
- 系统统一使用 32、30、28 三档字号适配，间距同步缩放，超出时正文滚动。
- 老师配置内容、拼音与换行；字号和行距由系统控制。
- 标题按汉字与拼音的实际宽度排列，完整字块一起换行。
- 拼音防重叠、中文标点换行、实际渲染行数。
- 草稿保存在当前浏览器本机，可以导出 JSON 配置。

## 本地运行

```sh
python3 -m http.server 4173
```

访问 `http://localhost:4173/`。无需安装依赖或构建。

## 发布

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保持静态文件原样部署。

## 字体

字体来源及授权说明见 `fonts/FONT-SOURCES.txt` 和 `fonts/` 内对应授权文件。
预览数字使用设计坐标，React Native 真机字号仍需独立校准。
